Write an array-based Queue that uses a CIRCULAR array of fixed size.

    const int MAX_QUEUE = 4;           // define this in your file, exactly 4

    class Queue {
    public:
        Queue();
        bool isEmpty() const;
        bool isFull() const;
        int  size() const;
        bool enqueue(int value);         // false if full
        bool dequeue();                  // false if empty
        bool dequeue(int& value);        // false if empty, value unchanged
        bool getFront(int& value) const; // false if empty, value unchanged
    private:
        int items[MAX_QUEUE];
        // + what you need (front, back, count ...)
    };

- No new / delete: only the fixed array.
- Indexes must wrap around with % MAX_QUEUE (no shifting items).
- Slides: chapter 7, "An Array-Based Implementation".

Example:

    enqueue 1 2 3 4   -> isFull true, enqueue 5 returns false
    dequeue, dequeue  -> got 1, 2
    enqueue 5 6       -> both true (back wrapped around)
    dequeue all       -> 3 4 5 6
