Assignment name  : ex06_merge_sorted
Expected file    : rendu/ex06_merge_sorted.cpp
Level            : 3
--------------------------------------------------------------------------------

Write a function that merges two sorted (ascending) singly linked lists into
one sorted list and returns its head.

Prototype:

    Node* mergeSorted(Node* a, Node* b);

- #include "../include/node.h"
- Do NOT create or delete nodes: relink the nodes you are given.
  The grader checks that every node in the result is one of the original nodes.
- Either list may be empty.
- Duplicates stay (they are not removed).

Examples:

    [1 3 5] + [2 4 6]   -> [1 2 3 4 5 6]
    [1 3 3] + [3 4]     -> [1 3 3 3 4]
    []      + [1 2]     -> [1 2]
    []      + []        -> []
